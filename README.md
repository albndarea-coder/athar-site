# أثر | رسالة لمعلّم — النسخة المستقلة

موقع إهداءات للمعلمين مع لوحة إدارة عربية. مبني على Node.js وحده بلا أي حزم خارجية، وقاعدة بياناته SQLite المدمجة في Node.js. لذلك يمكن نقله إلى أي استضافة تشغّل Node.js 22.13 أو أحدث، أو Docker.

- واجهة الزوار: `/`
- لوحة الإدارة: `/admin`
- البيانات الدائمة (قاعدة البيانات والصور): داخل المجلد المحدد في `DATA_DIR`

---

## 1. التشغيل على جهازك (للتجربة)

```bash
# يتطلب Node.js 22.13 أو أحدث
cd athar
SETUP_TOKEN=اكتبي-رمزا-طويلا npm start
```

افتحي `http://localhost:3000/admin`، وأدخلي الرمز نفسه لإنشاء حساب المالك.
لا يحتاج المشروع إلى `npm install` لأنه بلا اعتماديات.

تشغيل الاختبارات:

```bash
npm test
```

## 2. النشر على حساباتك (GitHub + Railway)

اخترت Railway لأن الموقع المرجعي مستضاف عليه. يمكنك استخدام أي استضافة أخرى (القسم 6).

### أ) المستودع على GitHub
1. أنشئي مستودعًا **خاصًا** جديدًا في حسابك على GitHub، باسم مثل `athar-site`.
2. ارفعي محتويات مجلد المشروع إليه، إما بزر **Add file ← Upload files** في GitHub (اسحبي كل الملفات والمجلدات)، أو بالأوامر:
   ```bash
   git init && git add . && git commit -m "النسخة الأولى"
   git branch -M main
   git remote add origin https://github.com/<حسابك>/athar-site.git
   git push -u origin main
   ```

### ب) الاستضافة على Railway
1. سجّلي الدخول في railway.com بحساب GitHub نفسه.
2. **New Project ← Deploy from GitHub repo** ← اختاري `athar-site`. سيبني Railway المشروع تلقائيًا من `Dockerfile`.
3. أضيفي قرصًا دائمًا: من الخدمة اختاري **Settings ← Volumes ← Add Volume**، واجعلي مسار التركيب (Mount path) هو `/data`.
   **هذه الخطوة ضرورية.** بدونها تُمحى البيانات مع كل نشر.
4. من **Variables** أضيفي:
   | المتغير | القيمة |
   |---|---|
   | `DATA_DIR` | `/data` |
   | `NODE_ENV` | `production` |
   | `TRUST_PROXY` | `1` |
   | `SETUP_TOKEN` | قيمة عشوائية طويلة تُولّدينها بنفسك (انظري القسم 3) |
   | `IP_HASH_SALT` | قيمة عشوائية طويلة أخرى |
5. من **Settings ← Networking ← Generate Domain** تحصلين على رابط مثل `athar-xxxx.up.railway.app`.
6. اسم نطاق خاص بك (اختياري): اشتريه من أي مسجّل نطاقات باسمك، ثم من **Custom Domain** في Railway أضيفيه، وانسخي سجل CNAME الذي يعرضه Railway إلى إعدادات النطاق لدى المسجّل.

### التكاليف (تحقّقي منها قبل التفعيل)
- **Railway:** خطة Hobby بسعر 5 دولارات شهريًا، وتشمل 5 دولارات من الاستهلاك. توجد أيضًا تجربة مجانية برصيد لمرة واحدة. يُحسب القرص الدائم ضمن الاستهلاك؛ راجعي سعره الحالي في صفحة الأسعار railway.com/pricing. موقع بهذا الحجم يبقى غالبًا ضمن الرصيد المشمول، لكن التكلفة الفعلية تعتمد على الزيارات.
- **اسم النطاق:** اختياري، ويُدفع سنويًا لدى المسجّل.
- **GitHub:** المستودع الخاص مجاني.
- لا يستخدم المشروع أي خدمة مدفوعة أخرى، ولم أفعّل أي اشتراك.

## 3. تفعيل حساب المالك بأمان

**الطريقة الأولى (من المتصفح):**
1. ولّدي رمزًا عشوائيًا على جهازك:
   ```bash
   node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
   ```
   أو استخدمي أي مولّد كلمات مرور واختاري 30 حرفًا أو أكثر.
2. ضعيه في المتغير `SETUP_TOKEN` في Railway، ثم انتظري إعادة النشر.
3. افتحي `https://نطاقك/admin`، وأدخلي الرمز وبريدك وكلمة مرور قوية (10 أحرف على الأقل).
4. **احذفي `SETUP_TOKEN` من المتغيرات فورًا.** صفحة الإعداد تتوقف تلقائيًا بعد إنشاء أول حساب، لكن حذف الرمز أكثر أمانًا.

**الطريقة الثانية (من الطرفية):** إن كان لديك وصول لطرفية الخادم، شغّلي `npm run create-owner`. تُكتب كلمة المرور مخفية، ولا تُحفظ في أي ملف.

### استعادة الوصول إن نسيتِ كلمة المرور
- **من الطرفية:** `npm run reset-password`.
- **من المتصفح:** اضبطي المتغير `RECOVERY_TOKEN` بقيمة عشوائية مؤقتًا. سيظهر رابط «نسيت كلمة المرور؟» في صفحة الدخول. أدخلي الرمز وبريد المالك وكلمة مرور جديدة، ثم **احذفي المتغير**.

لا يحتوي المشروع أي حساب مخفي أو كلمة مرور ثابتة أو وسيلة دخول لطرف آخر. كلمات المرور تُخزَّن مُجزّأة (scrypt)، والصلاحيات تُفحص على الخادم في كل طلب.

## 4. دليل لوحة الإدارة

### المحتوى والتصميم
- **التعديل كمسودة:** كل تعديل يُحفظ في «المسودة» ولا يراه الزوار.
  - **حفظ المسودة:** يحفظ دون نشر.
  - **معاينة:** تعرض المسودة بمقاس الجوال أو التابلت أو الكمبيوتر.
  - **نشر:** يجعل التعديلات ظاهرة للزوار، ويحفظ نسخة في السجل.
  - **تجاهل التعديلات:** يعيد المسودة إلى آخر نسخة منشورة.
- **الصفحات والأقسام:** عدّلي نصوص أي قسم من زر «تعديل». رتّبي الأقسام بالسهمين، وأخفيها أو احذفيها. الحذف ينقل القسم إلى «المحذوفات» ويمكن استعادته. يمكنك إضافة أقسام نصية أو صور، وإضافة صفحات جديدة تظهر على الرابط `/p/اسم-الرابط`.
- **تمييز كلمة:** ضعيها بين قوسين مزدوجين، مثل `[[أثركم]]`، فتظهر باللون والخط السفلي كما في البطاقة الرئيسية.
- **القائمة:** رتّبي روابط الترويسة أو أخفيها أو أضيفي روابط جديدة.
- **نافذة الهدية والتوقيع:** كل نصوص نافذة «كلمة إكبار وامتنان»، ومنها حقل **التوقيع**. قيمته الحالية: «أ.البندري السلمي ث٣٥ بمكة».
- **الألوان والخط:** كل ألوان الموقع، ومنها **لون التوقيع**. تعرض الصفحة فحصًا للتباين، وفيها زر لاستعادة الألوان الافتراضية. الخط الافتراضي Tajawal، ولا يتغير إلا إذا غيّرتِه.
- **الإعدادات:** تفعيل مراجعة الإهداءات قبل ظهورها.

### الإهداءات
تشمل: الاعتماد والإخفاء والتعديل والحذف والاستعادة، وتصدير CSV يفتح في Excel.
تصنيف «معلم/معلمة» في الحديقة يُحدَّد من هنا لكل إهداء، لأن النموذج لا يطلبه من الزائر.

### الصور
ارفعي صور PNG أو JPG أو WEBP أو GIF (حتى 5 ميغابايت)، واستخدميها في أي حقل صورة.

### المستخدمون والصلاحيات (للمالك فقط)
| الدور | يستطيع |
|---|---|
| محرر | تعديل المسودة، وإدارة الإهداءات، ورفع الصور |
| مدير | ما سبق، مع النشر والسجل والتصدير وحذف الصور |
| مالك | كل شيء، ومنه المستخدمون والنسخ الاحتياطي والاستعادة |

لا يمكن حذف آخر مالك أو تعطيله أو تخفيض دوره.

### السجل والنشر
يحفظ السجل كل عملية نشر، ويمكن استعادة أي نسخة سابقة إلى المسودة. يعرض أيضًا سجل العمليات الإدارية.

### النسخ الاحتياطي والاستعادة (للمالك)
- **تنزيل النسخة الاحتياطية:** ملف JSON واحد يحوي كل شيء: المحتوى والسجل والإهداءات والمستخدمين والصور. احفظيه في مكان آمن.
- **الاستعادة:** تستبدل كل البيانات بمحتوى الملف، وتُنهي الجلسات.
- يُنصح بتنزيل نسخة أسبوعيًا، وقبل أي تعديل كبير.

## 5. نقل الموقع إلى استضافة أخرى
1. من اللوحة القديمة: **النسخ الاحتياطي ← تنزيل**.
2. انشري الكود نفسه على الاستضافة الجديدة: Render أو Fly.io أو خادم VPS أو أي خدمة تدعم Docker أو Node.js 22.13 فأحدث. اضبطي `DATA_DIR` على مجلد دائم، و`SETUP_TOKEN`.
3. أنشئي حساب مالك مؤقتًا، ثم **النسخ الاحتياطي ← استعادة** بالملف المنزّل.
4. سجّلي الدخول بحسابك الأصلي، واحذفي `SETUP_TOKEN`.

يمكن أيضًا نسخ ملفات المجلد `DATA_DIR` كما هي (`athar.db` ومجلد `uploads`) بعد إيقاف الخادم.

## 6. التراخيص والحقوق
- **الكود:** كُتب لهذا المشروع، وملكيته لك.
- **الخط Tajawal:** ترخيص SIL Open Font License 1.1. يُحمَّل من Google Fonts.
- **الأيقونات:** من مكتبة Lucide، بترخيص ISC، ومضمّنة في `public/js/icons.js`.
- **المحتوى والتصميم المرجعي:** النصوص والتخطيط وصورة الملصق منقولة من موقع «أثر» المرجعي. ملكيتها الفكرية لصاحبته، ويلزم إذنها لاستخدامها علنًا.
- **صورة ملصق اليوم العالمي للمعلمين:** المرفقة نسخة مقتطعة منخفضة الدقة من لقطة الشاشة. استبدليها بالملف الأصلي من «الصور» إن توفّر لديك، وتأكدي من حق استخدامه.
